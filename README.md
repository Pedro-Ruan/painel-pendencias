

## Versão com Anexar Apólices — 04/11/2026

Nova página apolices.html com regras compartilhadas de eficiência e SUSEP, histórico recebido, filtros de datas, gráficos interativos, edição de organização com salvar/cancelar e restauração individual, tabela reorganizável, exportação XLSX filtrada e dias parados. O contador destaca mais de 2 dias, sem mudar os prazos de Pendências. As abas usam estilo de botão em ambos os temas, inclusive após visita.

Para conectar, publique o Worker R5 e configure GOALFY_APOLICES_REPORTS com os novos links somente no Cloudflare. Preserve GOALFY_REPORTS de Pendências. Endereço e senha são informados no painel. Consulte integracao/APOLICES.md. Não envie segredos, links privados ou relatórios ao GitHub.
